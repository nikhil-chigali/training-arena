# Training Arena

A personal sandbox for hands-on practice alongside courses in:

- **Generative AI** — prompting, RAG, fine-tuning, multimodal models
- **AI Engineering** — building and deploying AI-powered applications
- **ML Engineering** — model development, evaluation, and serving
- **LLMOps** — managing LLM lifecycles, monitoring, and evaluation pipelines
- **MLOps** — CI/CD for ML, experiment tracking, model registries
- **Agentic Applications** — multi-agent systems, tool use, orchestration frameworks

## Courses

Course progress is tracked on the [GitHub Projects board](../../projects) using a Kanban board with **Planned**, **In Progress**, and **Completed** columns.

## Structure

Code, notebooks, and experiments will be organized by course/topic as the work progresses.
